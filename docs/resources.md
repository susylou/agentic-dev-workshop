## Where next

### Keep building with Build Agent

You don't need today's workshop instance to carry on. Two routes:

| Route | How to get it | Build Agent prompts |
|---|---|---|
| **Personal Developer Instance (PDI)** | Free from [developer.servicenow.com](https://developer.servicenow.com). Must be a **Zurich or later** instance. | **25 per month** |
| **Your company's sub-production instance** | Ask your account team whether you're eligible for **Now Assist for Creator** — or install **Build Agent (Trial)** from the ServiceNow Store. | **100 per month** with the Trial |

!!! note "You'll need the admin role"
    Build Agent requires `admin` on whichever instance you use. On a PDI that's you by
    default; on a company sub-prod instance you may need to ask.
